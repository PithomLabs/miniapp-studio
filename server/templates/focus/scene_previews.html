Previews

Three preview kinds, three honest states. Only dry-run fixture previews execute today; the other two are designed and labeled, with no controls pretending otherwise.

Which preview is which

KindStateWhat it is
Dry-runFunctionalFixture execution on the builder. Run one.
Workspace PreviewPlannedA live look at the Builder's working tree for the current task. No backend yet.
Application PreviewPlannedPer-PR deployed preview with identity, commit, URL, health, and expiry. Preview controller is T3-gated.

Engineering PR Preview (this page, for reviewers) and customer Application Preview (for end users) are separate lifecycles sharing nothing but the artifact digest. They are never merged here.
